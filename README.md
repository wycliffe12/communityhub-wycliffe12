# CommunityHub — wycliffe12

React + Vite starter project for the IYF Season 12 component exercise.

## Run locally

1. Open this `communityhub-wycliffe12` folder in VS Code.
2. Open Terminal → New Terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed in the terminal (usually http://localhost:5173).

## Exercise files

- `src/exercises/wycliffe12/App.jsx` — main exercise component
- `src/exercises/wycliffe12/App.css` — exercise styles
- `src/components/Header.jsx` — reusable header
- `src/components/Footer.jsx` — reusable footer

The root app imports the exercise from `src/App.jsx`.
